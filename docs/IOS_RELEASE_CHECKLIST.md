# iOS Release Checklist

Review date: 2026-06-23

- Configure bundle ID, signing, and capabilities.
- Lock portrait orientation.
- Add native splash.
- Generate `Localizable.strings` and `.stringsdict`.
- Localize `NSUserTrackingUsageDescription`.
- Configure AdMob app ID and ad unit IDs via config.
- Configure UMP and ATT sequence.
- Configure Unity and Meta mediation in AdMob.
- Configure Game Center achievements, leaderboards, and saved games.
- Configure StoreKit products.
- Configure App Privacy Details.
- Configure screenshots and app preview requirements.
- Validate no ads during active gameplay.
- Validate restore purchases.
- Archive with Xcode and upload to App Store Connect.
