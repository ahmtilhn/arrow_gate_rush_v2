# Play Games Setup

Review date: 2026-06-23

## Features

- Play Games Services v2 sign-in.
- Achievements.
- Leaderboards.
- Saved Games/Snapshots.
- Offline submission queue.

## Manual Setup

- Create Play Games Services project.
- Add game services project ID to Android string resources.
- Configure achievements and leaderboards.
- Enable Saved Games.
- Link OAuth/client configuration.
- Test internal release with Play services available.

## App Rule

Sign-in failure never blocks gameplay.
