# Game Center Setup

Review date: 2026-06-23

## Features

- Game Center authentication.
- Achievements.
- Leaderboards.
- Saved games through GameKit/iCloud plan.
- Native UI entry points.

## Manual Setup

- Enable Game Center capability.
- Configure achievements and leaderboards in App Store Connect.
- Configure iCloud/GameKit save capability if used.
- Test sandbox Game Center accounts.

## App Rule

Authentication failure never blocks gameplay.
